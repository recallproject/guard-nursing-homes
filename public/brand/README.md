# OversightReports brand lockup

Static lockup files for email signatures and other HTTPS embeds. Vite copies `public/` to the site root, same as `/samples/`.

| File | Size |
| --- | --- |
| `oversightreports-lockup.png` | Full-size lockup, 1280×720 |
| `oversightreports-lockup-email.png` | Email-sized lockup, 480×270 |

After deploy:

- https://www.oversightreports.com/brand/oversightreports-lockup.png
- https://www.oversightreports.com/brand/oversightreports-lockup-email.png

`https://oversightreports.com/brand/...` redirects to the `www` host.
